关于 树洞日记网

1. 网站简介：

树洞日记网是一款集个人日记记录与匿名树洞倾诉于一体的网页平台，用户可以自由书写日常心情，也可以在匿名树洞发布心事、匿名留言评论。


2. 开发技术：

采用 HTML5 + CSS3 + JavaScript 开发，布局简洁美观，页面统一风格，实现页面跳转、表单提交、匿名发帖、匿名评论等基础交互功能。


3. 设计目的：

为使用者提供一个私密、温柔的情绪记录与倾诉空间，同时作为网页设计课程答辩作品，巩固前端网页制作基础技术。


4. 功能模块：

首页导航、个人日记撰写、匿名树洞发帖、匿名评论、关于本站介绍。
